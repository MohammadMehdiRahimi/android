# Proposal: ویرایش ابعاد و رنگ چیپ‌های فیلتر صفحه لیگ (Filter Chips Refinement)

## 1. Description (توضیحات)
تنظیم و بهینه‌سازی استایل چیپ‌های فیلتر (همه، دوستان، اطراف من، قوانین لیگ):
1. **کاهش ارتفاع:** کاهش ارتفاع باکس هر چیپ به حدود 36dp (از 42dp).
2. **افزایش عرض (Padding افقی):** افزایش پدینگ افقی محتوای داخل هر چیپ به حدود 20dp الی 22dp برای عریض‌تر و کشیده‌تر شدن دکمه‌ها.
3. **رنگ بنفش‌تر و غنی‌تر:** استفاده از رنگ بنفش عمیق‌تر و زنده‌تر (مانند `#582BE8` یا `#6320EE` یا `#6B21A8` / `#4F46E5`) برای تب انتخاب‌شده.

## 2. Acceptance Criteria
- [ ] ارتفاع چیپ‌های فیلتر کاهش یابد.
- [ ] عرض و پدینگ افقی هر چیپ افزایش یابد.
- [ ] رنگ بنفش چیپ انتخاب‌شده شاداب‌تر و بنفش‌تر شود.
