# Design Specification: Exact Arc Button Layout Matching Image

## 1. UI & Layout Architecture
یک کامپوننت اختصاصی یا بخش بازطراحی‌شده برای کنترل‌های تایمر پیاده‌سازی می‌شود که شامل یک `Canvas` یا مسیر منحنی پس‌زمینه (Orbital Arc Track) با رنگ ملایم `Color(0xFFE2E8F0)` یا `Color(0xFFEDE9FE)` است.

### چینش هندسی دکمه‌ها (از راست به چپ در RTL):
1. **دکمه ۱ (راست): بازنشانی (Reset)**
   - اندازه دایره: ۴۸dp الی ۵۰dp
   - رنگ پس‌زمینه: سفید خالص (`Color.White`) با سایه ملایم و استروک `Color(0xFFF1F5F9)`
   - رنگ آیکون: بنفش پررنگ `Color(0xFF7C3AED)`
   - آیکون: `Icons.Outlined.RestartAlt`
   - متن زیر دکمه: «بازنشانی» با رنگ `Color(0xFF6B21A8)`

2. **دکمه ۲: اتمام دور (Finish Round)**
   - اندازه دایره: ۴۸dp الی ۵۰dp
   - رنگ پس‌زمینه: سفید خالص با سایه ملایم
   - رنگ آیکون: نارنجی جذاب `Color(0xFFF97316)`
   - آیکون: `Icons.Filled.Flag` یا `Icons.Outlined.Flag`
   - متن زیر دکمه: «اتمام دور» با رنگ `Color(0xFFF97316)`
   - عملکرد: اتمام موفق دوره جاری، افزایش شمارنده دورها و ثبت پیشرفت در دیتابیس.

3. **دکمه ۳ (مرکز): شروع / توقف (Play / Pause Hero)**
   - اندازه دایره: ۶۴dp الی ۶۸dp (بزرگ‌تر از بقیه)
   - رنگ پس‌زمینه: سفید خالص با سایه شیشه‌ای نرم (`shadowElevation = 4.dp`)
   - رنگ آیکون: بنفش پررنگ `Color(0xFF7C3AED)`
   - آیکون: `Icons.Filled.PlayArrow` / `Icons.Filled.Pause`
   - متن زیر دکمه: «شروع» یا «توقف» با رنگ `Color(0xFF7C3AED)`

4. **دکمه ۴: رد کردن این دور (Skip Round)**
   - اندازه دایره: ۴۸dp الی ۵۰dp
   - رنگ پس‌زمینه: سفید خالص با سایه ملایم
   - رنگ آیکون: صورتی/مرجانی `Color(0xFFF43F5E)`
   - آیکون: `Icons.Outlined.Autorenew` یا `Icons.Outlined.Sync`
   - متن زیر دکمه: «رد کردن این دور» با رنگ `Color(0xFFF43F5E)`
   - عملکرد: رد کردن دور جاری و شروع دوره بعد.

5. **دکمه ۵ (چپ): موسیقی (Music / Sound)**
   - اندازه دایره: ۴۸dp الی ۵۰dp
   - رنگ پس‌زمینه: سفید خالص با سایه ملایم
   - رنگ آیکون: بنفش پررنگ `Color(0xFF7C3AED)`
   - آیکون: `Icons.Outlined.MusicNote`
   - متن زیر دکمه: «موسیقی» با رنگ `Color(0xFF1E1B4B)`
   - عملکرد: باز کردن مودال انتخاب صوت و نویز تمرکز.

## 2. ساختار هلالی و خط اتصال (Arc Curve with Background Track Line)
- یک مسیر منحنی در پس‌زمینه دکمه‌ها رسم می‌شود که دکمه‌ها دقیقا بر روی آن با جابجایی مناسب عمودی قرار می‌گیرند:
  - دکمه‌های کناری (بازنشانی و موسیقی): `offset(y = (-14).dp)`
  - دکمه‌های میانی (اتمام دور و رد کردن): `offset(y = (-2).dp)`
  - دکمه مرکزی (شروع): `offset(y = 12.dp)`
- متن‌های زیر دکمه‌ها با فونت ایران‌سنس (`IranSansFontFamily`) و سایزهای دقیق ۱۱sp تا ۱۲sp درج می‌شوند.
