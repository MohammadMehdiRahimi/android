# Proposal: ویرایش‌های اختصاصی کارت کاربر، نوار پیشرفت و سکوی قهرمانی صفحه لیگ (League Screen Enhancements)

## 1. Description (توضیحات)
اعمال ویرایش‌های تکمیلی روی کامپوننت‌های صفحه لیگ:
1. **نوار پیشرفت (Progress Bar):**
   - کاهش ارتفاع پروگرس بار (مثلاً 5dp الی 6dp).
   - تیره‌تر کردن رنگ نوار پیشرفت (استفاده از بنفش تیره‌تر / سرمه‌ای-بنفش مانند `Color(0xFF4F46E5)` یا `Color(0xFF4338CA)`).
2. **کارت پروفایل کاربر (Hero League Card):**
   - بزرگ‌تر کردن اندازه تصویر پروفایل کاربر (افزایش قطر به حدود 88dp الی 92dp).
   - ایجاد همپوشانی عمودی (Overlap) و برجسته بودن آواتار بر روی بخش «تا رتبه بعدی».
   - قرار دادن تصویر دیفالت پروفایل کاربر در صورت نبودن تصویر (یا هندل کردن Fallback placeholder).
   - قرار دادن بوردر سفید (White border) ضخیم و تمیز دور آواتار کاربر با سایه ملایم.
   - تغییر رنگ پس‌زمینه کل کارت به خاکستری خیلی روشن و مینیمال (`#FAFAFA` یا `#F8FAFC`).
3. **متن‌ها و اعداد آمار سه‌گانه (رتبه، امتیاز، تا رتبه بعدی):**
   - کوچک‌تر کردن سایز فونت عنوان‌ها و اعداد رتبه، امتیاز و تا رتبه بعدی.
4. **سکوی ۳ نفر اول، دوم و سوم (Podium):**
   - قرار دادن تصویر/آواتار ماک برای نفرات اول، دوم و سوم.
   - حذف بوردر رنگی اطراف تصویر و حذف بوردرهای اضافه اطراف اسم‌ها.
   - اعمال پس‌زمینه (Background) روشن و شیک متناسب با هر جایگاه (رتبه ۱ زرد/طلایی ملایم، رتبه ۲ نقره‌ای/خاکستری-آبی ملایم، رتبه ۳ هلویی/نارنجی ملایم).
   - اعمال `RoundedCornerShape(topStart = 16.dp, topEnd = 16.dp, bottomStart = 0.dp, bottomEnd = 0.dp)` برای کارت‌های ستون سکوی زیر اسم‌ها.

## 2. Acceptance Criteria
- [ ] ارتفاع پروگرس بار کمتر و رنگ آن تیره‌تر شود.
- [ ] تصویر پروفایل کاربر بزرگ‌تر با بوردر سفید و همپوشانی مناسب با ردیف اطلاعات زیرین پیاده‌سازی شود.
- [ ] رنگ پس‌زمینه کارت کاربر به خاکستری بسیار روشن تغییر کند.
- [ ] تایپوگرافی آمار ۳تایی کمی ریزتر و مرتب‌تر شود.
- [ ] ستون‌های نفرات ۱ و ۲ و ۳ با آواتار ماک مناسب، بدون بوردرهای رنگی ضخیم، با bg روشن متناسب و انحنای بالای گوشه‌ها (Top-Left & Top-Right Radius) طراحی شوند.
