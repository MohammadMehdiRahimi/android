# Design: طراحی و مشخصات فنی ویرایش‌های صفحه لیگ

## 1. Top Header
- فقط عنوان «لیگ» (`20.sp`, `FontWeight.ExtraBold`, `LeagueDarkNavy`) در وسط قرار گیرد.
- زیرعنوان به طور کامل حذف شود.

## 2. Hero League Card Layout
- **ردیف بالایی:**
  - سمت راست بصری: شیلد طلایی + عنوان «لیگ طلایی» + بج «فصل شهریور».
  - سمت چپ بصری: آواتار بزرگ کاربر با بوردر و نشان تاج بنفش.
- **ردیف آمار:**
  - سمت راست: «رتبه شما» (۱۲ بنفش).
  - وسط: «امتیاز شما» (۶۴۲۰ تیره).
  - سمت چپ: «تا رتبه بعدی» (۱۸۰ امتیاز).
- **پروگرس بار LTR:**
  - نوار افقی به صورت `LayoutDirection.Ltr` رندر شود.
  - عدد «۶۴۲۰ / ۶۶۰۰» در سمت چپ.
  - عبارت «مسیر تا لیگ الماس 💎» در سمت راست.
- **باکس پایین کارت:**
  - بک‌گراند: `Color(0xFFF8FAFC)` با بوردر `Color(0xFFF1F5F9)`.
  - آیکون کادو بنفش در سمت راست و متن با سایز `11.sp` و وزن `FontWeight.Medium` با رنگ خاکستری تیره/آبی `Color(0xFF475569)`.

## 3. Top 3 Podium Card
- سکوها با رنگ پایه بسیار ملایم (طرح کارت با پس‌زمینه سفید/کرم بسیار کم‌رنگ `Color(0xFFFFFBEB)` برای نفر اول، `Color(0xFFF8FAFC)` برای نفر دوم و سوم).
- چیدمان افقی (از راست به چپ):
  - راست: نفر ۲ (نگار رحیمی - ۸۲۱۰) با نشان نقره‌ای.
  - وسط: نفر ۱ (سینا قربانی - ۸۹۳۰) با نشان طلایی و ارتفاع بلندتر.
  - چپ: نفر ۳ (پارسا احمدی - ۷۲۸۰) با نشان برنزی.

## 4. League Table Compact Rows
- کاهش پدینگ عمودی ردیف‌ها به `4.dp` یا `5.dp`.
- آواتارها با اندازه `34.dp` الی `36.dp`.
- فونت نام کاربر `12.5.sp`، رتبه `13.sp` و امتیاز `11.5.sp`.
