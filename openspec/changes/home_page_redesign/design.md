# سند طراحی معماری و رابط کاربری (Design): بازطراحی صفحه اصلی (Home Page Redesign)

## ۱. تصمیمات کلیدی معماری و استراتژی پیاده‌سازی (Architectural Decisions)

### ۱.۱. استراتژی پیاده‌سازی نمودار عملکرد (Performance Curve Chart Strategy)
برای پیاده‌سازی نمودار «نمای کلی عملکرد» با دقت پیکسلی، دو رویکرد مورد بررسی قرار گرفت:
1. **کتابخانه‌های آماده (Vico / Compose-Charts):** قابلیت‌های سفارشی‌سازی محدود برای استایل‌های ترکیبی (مانند تول‌تیپ اختصاصی بنفش روی سه‌شنبه، بخش خط‌چین انتهای منحنی، گرادینت شفافیت اختصاصی زیر مسیر منحنی و اعداد فارسی هماهنگ).
2. **رسم اختصاصی با Canvas در Jetpack Compose (رویکرد برگزیده):** 
   - **چرا Canvas اختصاصی؟** ارائه انعطاف ۱۰۰٪ برای پیاده‌سازی دقیق خطوط Bézier، سایه‌های ملایم زیر خطوط، خط‌چین عمودی راهنما برای روز انتخاب‌شده، گره‌های دایره‌ای دورنگ، پین و تول‌تیپ شناور با گوشه‌های گرد و محتوای فارسی، و تغییر روان به خط‌چین برای روزهای آینده.
   - **راهکار پرفورمنس بدون افت فریم (60/120 FPS Rendering):**
     - محاسبه نقاط و ساخت اشیاء `Path` در بلوک `remember(points, width, height)` تا در هر فریم انیمیشن یا اسکرول، شیء جدید در حافظه (Heap Allocation) تخصیص داده نشود.
     - استفاده مستقیم از توابع بومی `DrawScope` (مانند `drawPath`, `drawCircle`, `drawLine`, `drawIntoCanvas`) با `Brush.verticalGradient`.
     - کش کردن اشیاء `Paint` و `PathEffect.dashPathEffect` خارج از حلقه رسم.

```
       [ داده‌های عملکرد روزانه (Performance Points) ]
                           │
                           ▼ (محاسبه و مقیاس‌دهی با remember)
       [ تولید مسیرهای هندسی (Cubic Bézier Paths) ]
          ├── 1. Solid Curve Path (شنبه تا پنجشنبه)
          ├── 2. Dashed Projection Path (پنجشنبه تا امروز)
          ├── 3. Filled Area Gradient Path (مساحت زیر نمودار)
          └── 4. Highlight Marker & Tooltip (روز سه‌شنبه)
                           │
                           ▼ (رسم در DrawScope)
       [ رندر فوق‌سریع Canvas بدون هیچگونه Garbage Collection ]
```

### ۱.۲. استراتژی پیاده‌سازی نوار ناوبری اختصاصی (Custom Floating Bottom Navigation)
- **ساختار هندسی و بصری:**
  - یک کانتینر شناور با فاصله از کناره‌ها (`horizontal padding = 18.dp`) و انتهای صفحه (`bottom padding = 8.dp`) با ارتفاع مشخص (`74.dp`) و شعاع گوشه ۳۴ دی‌پی (`RoundedCornerShape(34.dp)`).
  - استفاده از دکمه برجسته مرکزی (Elevated Floating Action Tab) برای تب «خانه» با قطر ۶۶ دی‌پی و شناور بودن رو به بالا (`offset(y = -18.dp)`).
  - سایه اختصاصی بنفش رنگ (`ambientColor` و `spotColor` برابر با `Color(0x337656F5)`).
- **حالت‌های تب‌ها:**
  - **تب فعال (Selected Tab):** تغییر رنگ آیکون و متن به بنفش برند (`#7656F5`) با فونت ضخیم (Bold).
  - **تب غیرفعال (Unselected Tab):** رنگ خنثی و مات (`#9CA4BC`) با وزن عادی.
  - **تب خانه (Home Tab):** دایره بزرگ بنفش با آیکون سفید خانه و درج عنوان متنی «خانه» در زیر دایره با فونت ایران‌سنس.

## ۲. مشخصات و ساختار مؤلفه‌ها (Component Specifications)

### ۲.۱. مؤلفه هدر (`HomeTopHeader`)
- **ابعاد و موقعیت:** لایه بالا با رعایت حاشیه‌های امن نوار وضعیت (`statusBarsPadding()`).
- **سمت چپ (Left):** دکمه اعلان‌ها (`size = 50.dp`) با کانتینر دایره‌ای سفید، سایه نرم، آیکون `NotificationsNone` و بج قرمز/بنفش برای تعداد پیام‌های جدید.
- **سمت راست (Right):** ترکیب ردیفی نام و برند:
  - متن «شتاب» یا نام کاربر با فونت ایران‌سنس سایز ۲۲sp با آیکون صاعقه بنفش `Bolt`.
  - زیرعنوان «مسیر پیشرفتت روشنم» یا عنوان کاربر با رنگ خاکستری مایل به سرمه‌ای (`#A0A8C0`).
  - آیکون پروفایل دایره‌ای با نشانگر سبز آنلاین بودن در گوشه پایین راست آواتار.

### ۲.۲. مؤلفه کارت‌های آماری چهارگانه (`HomeStatsRow`)
- ماتریس افقی متشکل از ۴ کارت متقارن با وزن مساوی (`weight(1f)`):

  | **رتبه من** | ۱۵ | `#7957EF` (بنفش) | `#F5F0FF` | `#9B75F5` | تاج / Crown |
  | **ناشگر برتر** | لول ۴ | `#21B982` (سبز) | `#EDF9F5` | `#30C58B` | ستاره هشت‌ضلعی / Badge |
  | **کل مطالعه** | ۱۴۸ ساعت | `#3D70EF` (آبی) | `#F1F5FF` | `#4D78EF` | ساعت / AccessTime |

### ۲.۳. مؤلفه نمودار عملکرد (`PerformanceChartCard`)
- **کانتینر:** کارت با گوشه‌های `24.dp`، پس‌زمینه سفید، پدینگ داخلی `18.dp`.
- **هدر کارت:**
  - سمت راست: آیکون نمودار صعودی بنفش + متن «نمای کلی عملکرد».
  - سمت چپ: دکمه پیل‌شکل سفید/خاکستری با فلش رو به پایین «هفته گذشته ⌄».
- **بدنه نمودار:**
  - خطوط راهنمای افقی نقطه‌چین/خاکستری ملایم (`#F0F2F8`).
  - لیبل‌های عمودی مقادیر ۰، ۲۵، ۵۰، ۷۵، ۱۰۰ در سمت راست.
  - منحنی اصلی بنفش (`#7656F5`) با ضخامت `3.dp` و سایه زیرین بنفش شفاف (`alpha = 0.25f` به `0.02f`).
  - گره‌های داده‌ها: دایره سفید با کادر بنفش پررنگ.
  - گره منتخب (روز سه‌شنبه): خط‌چین عمودی بنفش به پایین، دایره بزرگ‌تر و نشانگر بنفش متنی در بالای نقطه با متن سفید «سه‌شنبه».
  - خط منحنی روزهای پنجشنبه تا امروز به صورت خط‌چین (Dashed Bézier) برای نشان دادن امتداد زمانی.
  - لیبل‌های افقی روزهای هفته در پایین با چینش منظم.

### ۲.۴. مؤلفه گرید ویژگی‌ها (`HomeFeatureGrid`)
- **ردیف بالایی نامتقارن (ارتفاع ۲۴۵ دی‌پی):**
  - **ستون راست (در RTL):** شامل ۲ کارت روی هم:
    1. **لیگ‌های رقابتی فعال:** پس‌زمینه آبی ملایم (`#EFF6FF`)، آرت‌ورک سپر و جام، ردیف آواتارهای تودرتو، دکمه گرد ناوبری `<`.
    2. **گروه‌های مطالعاتی من:** پس‌زمینه سبز نعنایی (`#F0FDF4`)، کاراکترهای سه‌بعدی گروه، ردیف آواتارها، دکمه گرد ناوبری `<`.
  - **ستون چپ (در RTL):** کارت بزرگ عمودی **برنامه‌ریز هوشمند شتاب**:
    - پس‌زمینه بنفش ملایم (`#F5F3FF`)، عنوان دوسطری بنفش تیره، متن توضیحی، آرت‌ورک ۳D سیبل و دارت، دکمه پیل‌شکل تمام‌عرض بنفش با برچسب «شروع کنید >».
- **ردیف پایینی متقارن (ارتفاع ۱۲۰ دی‌پی):**
  - **کارت راست (در RTL):** **پرسش از همکلاسی‌ها** - پس‌زمینه بنفش روشن (`#FAF5FF`)، وکتور ۳D حباب‌های گفتگو، دکمه دایره‌ای بنفش `<`.
  - **کارت چپ (در RTL):** **آزمون‌ساز** - پس‌زمینه کرم طلایی (`#FFFBEB`)، وکتور ۳D دفترچه سوالات و مداد، دکمه دایره‌ای نارنجی `<`.

## ۳. جریان داده و مدیریت وضعیت (Data Flow & State Management)

```
[ سرور: GET /progress/dashboard & GET /performance ]
                      │
                      ▼
            [ ApiService / ApiClient ]
                      │
                      ▼
[ Presentation: ReferenceHomeDashboard / MainScreen ]
   ├── DashboardStatsState (رتبه، لیگ، ساعت مطالعه، امتیاز)
   ├── PerformanceChartState (نقاط روزهای هفته، مقادیر، روز منتخب)
   └── NavigationState (تب فعال و رویدادهای کلیک)
                      │
                      ▼
         [ رندر اجزای UI بازطراحی‌شده ]
```

## ۴. انطباق RTL و تایپوگرافی فارسی
- اعمال `LocalLayoutDirection provides LayoutDirection.Rtl` در تمامی سطوح صفحه اصلی.
- استفاده یکپارچه از فونت ایران‌سنس (`IranSansFontFamily`) و وزیرمتن (`VazirmatnFontFamily`).
- فرمت‌بندی تمامی مقادیر عددی با تابع `toPersianNumber()`.
- استفاده از جهت‌های منطقی `start` و `end` به جای `left` و `right`.
